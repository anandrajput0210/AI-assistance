# BMSIT&M CSE Department Website

A responsive React, Vite, TypeScript, and Tailwind CSS website concept for the Computer Science and Engineering department at BMS Institute of Technology & Management.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL after startup.

## Production build

```bash
npm run build
npm run preview
```

## Included pages

Home, About, Academics, Faculty, Research, Student Projects, Events, Achievements, Student Life, Careers, Notices, and Contact. Detail routes are included for faculty profiles, projects, events, and notices.

The site includes responsive navigation, page routing, a semester curriculum explorer, faculty and project filters, event and notice search/filter controls, achievement categories, local contact-form validation, reduced-motion support, and a back-to-top control.

## Content before publication

This is a website concept, not an official department publication. Sample faculty profiles, courses, projects, events, notices, achievements, and clubs are identified in the interface and stored in `src/data.ts`. Replace them with verified, approved information before publishing. Official vision/mission statements, contact details, facilities, curriculum, placement data, and partnerships have not been invented.

The contact form currently validates in the browser only. It does not send or store submissions. Connect an approved department mailbox or backend before using it for real enquiries.

## Images

Editorial photographs are loaded from Unsplash URLs. An internet connection is required to display them.
